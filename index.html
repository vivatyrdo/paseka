Настройки

Добавьте Groq API-ключи. Приложение сохранит их только в этом браузере. Не публикуйте их и отзывайте, если потеряете телефон.

Для разбора записей основной ключ использует GPT-OSS 120B, резервный — GPT-OSS 20B. При ошибке доступа к модели или временном сбое приложение пробует резервный ключ. При исчерпании лимита (429) приложение тоже пробует резервный ключ.

Groq рекомендует не хранить API-ключи в клиентском веб-приложении. Здесь ключ хранится на телефоне для личного прототипа; если сайт или устройство скомпрометированы, ключ может раскрыться.
