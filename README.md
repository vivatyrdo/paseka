# Пасечный журнал — прототип

Статическая PWA для Android. Данные, записи аудио и ключи хранятся локально в браузере телефона через IndexedDB и localStorage. Облачной базы в этом прототипе нет.

## Как пользоваться

1. Откройте приложение по HTTPS и добавьте его на главный экран Android.
2. В настройках вставьте основной Groq API-ключ (для GPT-OSS 120B) и резервный (для GPT-OSS 20B).
3. Нажмите «Начать запись», произнесите заметку, например «Семья номер один…», затем остановите запись.
4. Когда сеть появится, приложение отправит запись на русскую транскрибацию. Очередь можно обработать вручную кнопкой «Обработать очередь».
5. Для вопроса нажмите «Задать вопрос голосом», произнесите вопрос и остановите запись. Приложение сверит его с текстами журнала и покажет/озвучит ответ.
6. «Пример» добавляет демонстрационные записи; «Экспорт» сохраняет CSV без аудиофайлов и ключей.

## Важно

- Без сети можно записывать заметки и хранить их в очереди. Расшифровка и умный голосовой вопрос требуют сети и Groq API-ключа.
- Ключи хранятся на этом устройстве в браузере, не зашиты в исходники. Это личный прототип; Groq не рекомендует хранить секретные ключи в клиентском приложении. Отзывайте ключ при потере устройства.
- Основной ключ для разбора использует GPT-OSS 120B, резервный — GPT-OSS 20B. Резервный ключ включается при ошибке доступа к модели, авторизации и временном сетевом/серверном сбое. При 429 (исчерпании квоты) приложение пробует резервный ключ; если лимит исчерпан и там, запись остаётся в очереди.
- Аудио, текст и ключи не синхронизируются в облако. Очистка данных сайта в Chrome удалит локальный журнал. Регулярно используйте экспорт CSV; он не сохраняет исходное аудио.
- Микрофон браузера требует защищённого HTTPS-адреса.
