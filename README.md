# Пасечный журнал

Статическая PWA для Android. Записи и аудио хранятся в IndexedDB на телефоне. Без интернета заметки остаются в очереди; после подключения к сети приложение отправляет аудио в Groq для расшифровки и разбора.

## Работа

- «Записать в журнал» сохраняет голосовую заметку, расшифровывает её при доступе к сети и обновляет карточку семьи или отводка.
- «Спросить журнал» принимает голосовой или текстовый вопрос и ищет только в выбранном разделе.
- Семьи и отводки показывают текущие известные факты. Фильтры: «Все» и «С задачами». Удержание карточки открывает редактирование или удаление объекта с подтверждением.
- В заметках и лечении «Записать» разбирает команду: создать, дополнить, исправить, удалить или спросить. Например, «обработка 5 — …» создаёт №5, а «дополни обработку 5 — …» изменяет ту же карточку. Номера постоянные и не пересчитываются после удаления. Неясные команды показываются отдельно; они не становятся записями.
- Удаление голосом или текстом сначала показывает запрос подтверждения с перечнем затрагиваемых записей. Вопросы и команды ограничены текущим разделом. Офлайн-команды выполняются последовательно после подключения. Повторное выполнение одной команды не дублирует изменение.
- Цвет семей и отводков — оценка ИИ по последним известным значениям полей: 1–39 красный, 40–69 жёлтый, 70–100 зелёный. Объяснение видно внутри карточки. При нехватке данных, обработке новой записи или отсутствии наблюдений о состоянии более 30 дней цвет нейтральный. Старый год и состояние матки сбрасываются при сообщении о её замене. Оценка журнала не является диагнозом.
- Первый ключ Groq использует GPT-OSS 120B, резервный — GPT-OSS 20B. Whisper распознаёт русский язык. При сбое или исчерпании лимита приложение пробует резервный ключ.
- API-ключи находятся только в localStorage этого браузера. Не публикуйте их и отзовите, если устройство потеряно.
- Журнал не синхронизируется с облаком. Очистка данных сайта в браузере удалит заметки, аудио и ключи.

## Запуск

Откройте сайт по HTTPS в Chrome на Android, добавьте его на главный экран и внесите Groq API-ключи в настройках. Для работы микрофона требуется разрешение браузера.

## Проверка и публикация

Без внешних npm-зависимостей:

```sh
node --test --test-isolation=none tests/journal.test.cjs
node tests/browser-smoke.cjs
```

Браузерная проверка использует отдельный временный профиль Chrome/Edge, настоящую IndexedDB и тестовые ответы Groq. Личные ключи и профиль не используются. Для нестандартного пути браузера задайте `CHROME_PATH`. Проверяются миграция v1 → v2, постоянные номера, команды, подтверждения, независимость разделов, очередь без интернета, повторные вызовы, актуальность оценки и мобильная вёрстка. Живые ответы модели и микрофон этими проверками не проверяются.

При публикации файлы `index.html`, `styles.css`, `app.js`, `journal-core.js`, `journal-features.js`, `sw.js` должны совпадать с копиями в `dist`. Версия кэша задаётся в `sw.js`. IndexedDB v2 добавляет хранилище `meta`; старые записи сохраняются и получают постоянные номера по прежнему порядку отображения.
